```bash

```

Para ferramenta de navegador, aproveitar a instalação disponível no Cloud. Se for
necessário instalar a ferramenta temporária, usar diretório isolado:

```bash
mkdir -p .visual/f5/tools
npm install --prefix .visual/f5/tools --no-save --ignore-scripts --no-audit --no-fund @playwright/test@1.63.0
export NODE_PATH="$PWD/.visual/f5/tools/node_modules"
NODE_ENV=production IKCOUS_IDENTITY_MODE=fixture node .visual/f5/tools/node_modules/playwright/cli.js test --config tests/e2e/playwright.jornadas.config.ts jornada-compra-ate-carrinho jornada-carrinho-ate-endereco jornada-trocar-endereco-carrinho
```

Conferir a resolução da ferramenta e o Chromium preexistente antes da jornada. O
`NODE_PATH` pode não resolver todo import ESM; não alterar dependências versionadas para
contornar. O roteiro comum informa `/opt/pw-browsers` e proíbe instalação desnecessária.
O harness é documentado em [README da vitrine](../../../scripts/visual/vitrine/README.md).
Em Linux, seu comando básico é:

```bash
node scripts/visual/vitrine/rodar.mjs . .visual/f5/candidato --telas carrinho-vazio,carrinho-com-itens
node scripts/visual/vitrine/comparar.mjs .visual/f5/baseline .visual/f5/candidato
```

O baseline deve vir da base anterior às alterações, com build próprio; não comparar o
candidato consigo mesmo. Manter snapshots fora do versionamento conforme o README.
