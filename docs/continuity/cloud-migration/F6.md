```bash

npm run typecheck
npm run test:front -- tests/front/checkout tests/front/desktop-checkout tests/front/order-success
npm test
NODE_ENV=production IKCOUS_IDENTITY_MODE=fixture npm run build
npm run lint:links

IKCOUS_IDENTITY_MODE=fixture npm run size
```

Para as verificações pontuais, usar `npx eslint` e `npx biome check` nos seis
arquivos de código/teste listados acima. Não usar `eslint --fix` no arquivo todo
nem alterar a baseline de lint.

Se Playwright não estiver disponível, seguir o README do harness e a receita do
plano, sem alterar manifests/lockfiles do projeto. Chromium pode estar pronto
em `/opt/pw-browsers`; conferir antes de instalar outro.

npx playwright test --config tests/e2e/playwright.jornadas.config.ts
