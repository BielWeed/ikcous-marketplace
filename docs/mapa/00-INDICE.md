## Como usar esta pasta

1. **Regras do repositório**: [`AGENTS.md`](../../AGENTS.md) na raiz é a fonte
   única de instruções (escopo, papéis, dinheiro, mapa de risco, verificação,
   mural). Este mapa **não repete** essas regras: aponta para elas.
2. **Estado mais fresco do trabalho**: 
   [`docs/superpowers/passagem/2026-09-17-super-atualizacao/`](../superpowers/passagem/2026-09-17-super-atualizacao/00-LEIA-PRIMEIRO.md)
   — leia na ordem dos números. É o bastão da "super atualização", com o que
   está pronto, as frentes interrompidas, a fila do que falta e as decisões já
   tomadas com o dono (que não devem ser reabertas).
3. **Retrato verificado localmente**: [`01-estado-verificado-2026-09-18.md`](01-estado-verificado-2026-09-18.md)
   — fatos conferidos no disco em 18/09/2026 (git, contagens, o que está
   ausente nesta cópia). Tem data porque **envelhece**.
4. **Onde fica cada coisa no código**: [`02-mapa-do-codigo.md`](02-mapa-do-codigo.md).
5. **Como o app funciona** (papéis, dinheiro, convidado, verificação): [`03-funcionamento.md`](03-funcionamento.md).

## Convenção adotada (cultura deste repositório)

Este projeto tem o hábito de **não copiar números que envelhecem** para dentro
de documentos (ver os avisos de [`docs/onboarding/06-ESTADO-ATUAL.md`](../onboarding/06-ESTADO-ATUAL.md)).
Os arquivos aqui seguem a mesma regra: retratos levam **data no nome ou no
topo**, e números vivos moram na fonte — este mapa só diz **onde a fonte está**.
