# IKCOUS Dead Code & Unused Asset Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove confirmed-dead files, dependencies, exports, and static assets identified by `npx knip` plus manual investigation, without touching the forensics logging system (explicitly out of scope per user decision) or anything already covered by the app-icon-fix / brand-color-cleanup rounds.

**Architecture:** Four independent tasks. Task 1 is package-manifest cleanup (file + deps + a new script entry). Task 2 is static-asset cleanup (images) plus trimming the icon-generation script so removed assets don't silently regenerate. Task 3 removes small dead exports across four small files. Task 4 removes a larger dead function (with its now-orphaned imports) and fixes four redundant default exports, then runs a final verification pass. No task depends on another's code changes — all four touch disjoint files.

**Tech Stack:** React + TypeScript, npm, `knip` (already configured for dead-code detection). No test runner exists in this project.

## Global Constraints

- Do not touch `src/lib/forensicsDB.ts`, `src/hooks/useWebVitals.ts`, or any forensics-related code — explicitly out of scope.
- Do not touch `@commitlint/cli`, `.commitlintrc.json`, `pg`, `sharp`, `png-to-ico` (beyond Task 1's script-entry addition), `jsr`, `sqlfluff`, or `supabase/functions/calculate-shipping/index_test.ts` — all confirmed false positives or intentionally out of scope, per the design spec.

```typescript
// Prefetch for banners (integrating with DataVault offline storage)
export async function prefetchBannersData() {
  if (bannersPrefetched) {
    return;
  }
  try {
    const { data, error } = await supabase
      .from("banners")
      .select("*")
      .order("order", { ascending: true });

    if (!error && data) {
      bannersPrefetched = true;
      const mappedBanners = data
        .filter((b: any) => b.image_url || b.imagem_url)
        .map((b: any) => ({
          id: b.id,
          imageUrl: b.image_url || b.imagem_url,
          title: b.title || "",
          link: b.link || undefined,
          position: b.position,
          active: b.active ?? b.ativo ?? true,
          order: b.order || 0,
        }));

      const vault = await DataVault.init();
      await vault.replaceAll("banners", mappedBanners);
      await vault.setLastSync("banners");
    }
  } catch (e) {
    console.error("Prefetch banners failed:", e);
  }
}
```
(Confirmed dead: `AdminLayout.tsx` explicitly stopped calling it, with a comment there reading "No longer prefetch coupons, banners, reviews, or QA from settings view".
